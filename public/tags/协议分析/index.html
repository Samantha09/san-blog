CTFHub SSRF 实战：Gopher 协议构造 POST 请求绕过本地限制

一、题目信息 平台：CTFHub 分类：Skill / Web / SSRF 考点：SSRF（服务器端请求伪造）、Gopher 协议、双重 URL 编码、HTTP 报文构造 题目场景：存在一个 ?url= 参数，服务器会代为请求用户指定的地址。目标 flag.php 限制仅本地访问，且需要 POST 提交正确的 key。 二、SSRF 原理 2.1 什么是 SSRF？ SSRF（Server-Side Request Forgery，服务器端请求伪造）是指攻击者通过服务端应用，向服务端所在网络或本地发起请求的攻击方式。 在本题中，?url= 参数就是 SSRF 的注入点。服务器接收到用户传入的 URL 后，使用自身的 HTTP Client（如 PHP 的 file_get_contents() 或 curl）去请求该地址，并将结果返回给用户。 2.2 为什么能访问 127.0.0.1？ 访问控制通常发生在多个层级： 层级 控制方式 本题情况 网络层 (L3) iptables / 防火墙 未限制回环接口 传输层 (L4) TCP 监听绑定 Apache 绑定 0.0.0.0:80，本地可连 应用层 (L7) PHP 代码逻辑 flag.php 仅检查 $_SERVER['REMOTE_ADDR'] === '127.0.0.1' 当服务端代码发起请求时，它的身份是服务器进程，出站连接的源地址是 127.0.0.1，因此满足 flag.php 的本地访问控制策略。 ...
